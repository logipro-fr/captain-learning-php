# Configuration JWT TTL / JWT TTL Configuration

## Français

### Que fait ce script bash ?

Le script bash `configure_jwt_ttl` est une fonction d'installation qui configure automatiquement la durée de vie (TTL - Time To Live) des tokens JWT pour l'authentification.

#### Fonctionnement détaillé :

1. **Affichage du message** : Indique qu'il commence la configuration du TTL des tokens JWT
   
2. **Définition de la valeur TTL** : 
   - Lit la variable d'environnement `JWT_TTL`
   - Si elle n'est pas définie, utilise la valeur par défaut de 3600 secondes (1 heure)
   
3. **Création du fichier de configuration** :
   - Crée un fichier YAML à `config/packages/lexik_jwt_authentication_local.yaml`
   - Ce fichier surcharge la configuration par défaut de `lexik_jwt_authentication.yaml`
   - Configure le paramètre `token_ttl` avec la valeur définie
   
4. **Confirmation** : Affiche un message confirmant la création du fichier avec la valeur TTL utilisée

#### Variables d'environnement :

- **JWT_TTL** : (Optionnel) Durée de vie des tokens JWT en secondes
  - Valeur par défaut : 3600 (1 heure)
  - Exemple : `JWT_TTL=7200` pour 2 heures

#### Fichier généré :

- **config/packages/lexik_jwt_authentication_local.yaml** : Fichier de configuration YAML auto-généré
  - Ce fichier est ignoré par git (ajouté dans .gitignore)
  - Il surcharge les paramètres de configuration JWT par défaut
  - Contient uniquement le paramètre `token_ttl`

#### Utilisation :

```bash
# Avec la valeur par défaut (3600 secondes)
./install

# Avec une valeur personnalisée (7200 secondes = 2 heures)
JWT_TTL=7200 ./install
```

## English

### What does this bash script do?

The `configure_jwt_ttl` bash script is an installation function that automatically configures the Time To Live (TTL) of JWT tokens for authentication.

#### Detailed operation:

1. **Display message**: Indicates that it's starting JWT token TTL configuration
   
2. **Set TTL value**: 
   - Reads the `JWT_TTL` environment variable
   - If not set, uses the default value of 3600 seconds (1 hour)
   
3. **Create configuration file**:
   - Creates a YAML file at `config/packages/lexik_jwt_authentication_local.yaml`
   - This file overrides the default `lexik_jwt_authentication.yaml` configuration
   - Sets the `token_ttl` parameter with the defined value
   
4. **Confirmation**: Displays a message confirming file creation with the TTL value used

#### Environment variables:

- **JWT_TTL**: (Optional) JWT token time-to-live in seconds
  - Default value: 3600 (1 hour)
  - Example: `JWT_TTL=7200` for 2 hours

#### Generated file:

- **config/packages/lexik_jwt_authentication_local.yaml**: Auto-generated YAML configuration file
  - This file is ignored by git (added to .gitignore)
  - It overrides default JWT configuration settings
  - Contains only the `token_ttl` parameter

#### Usage:

```bash
# With default value (3600 seconds)
./install

# With custom value (7200 seconds = 2 hours)
JWT_TTL=7200 ./install
```

## Technical Details

### Script Function

```bash
function configure_jwt_ttl() {
  echo "Configuring JWT token TTL..."
  TTL_VALUE="${JWT_TTL:-3600}"
  
  LOCAL_CONFIG="config/packages/lexik_jwt_authentication_local.yaml"
  
  cat > "$LOCAL_CONFIG" <<-EOF
	# Auto-generated by install script, overrides lexik_jwt_authentication.yaml
	lexik_jwt_authentication:
	    token_ttl: ${TTL_VALUE}
	EOF
  
  echo "Created ${LOCAL_CONFIG} with token_ttl: ${TTL_VALUE}s"
}
```

### Integration

This function is:
- Defined in `install-lib/configure-jwt.sh`
- Sourced by the `install` script
- Called during Step 1 of the installation process (after directory creation)
- Executed automatically every time `./install` is run

### Configuration Override

The generated local configuration file follows Symfony's configuration merging strategy:
- `lexik_jwt_authentication.yaml` contains the default settings
- `lexik_jwt_authentication_local.yaml` overrides specific settings
- Only the `token_ttl` parameter is overridden, other settings remain unchanged
